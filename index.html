AI Code of Conduct

House rules for working with AI on a team.

AI writes code now. AI drafts messages now. That's fine — but it doesn't get to make the call, and it definitely doesn't get to take the blame. This is a short, living list of ground rules. Two so far. More when we hit a new edge case.

Rule 1

Own your AI-generated code

You hit merge. You own it — no matter who, or what, wrote the diff.

  • Read every line before you ask someone else to.
  • Be able to explain any line in review, in your own words.
  • "The AI wrote it" is not a defense for a bug, a bad pattern, or an unreviewed dependency.
  • Reviewers hold AI-assisted code to the exact same bar as hand-written code — not lower.

The model doesn't get a byline. It doesn't get the blame either. You do.

#own-it
Rule 2

Communicate like a human, over Slack or Teams

Chat is for people talking to people. Keep it that way.

  • Don't paste raw model output into a DM and call it your opinion.
  • If a message, summary, or decision is AI-drafted, rewrite it in your own voice — or say so.
  • Skip the AI-flavored filler: no "I hope this message finds you well," no seven bullet points for a one-line question.
  • Keep it as short as you'd write it yourself. Shorter, ideally.

Your teammates are talking to you. Don't make them talk to your assistant instead.

#be-human
