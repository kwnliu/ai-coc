# ai-coc

**AI Code of Conduct** — a nohello.net-style single page of house rules for
working with AI on a team. Terse, shareable, link straight to a rule mid-conversation.

Live in `index.html` (no build step, no dependencies — just open it or serve it statically).

## Rules so far

1. **Own your AI-generated code** during code review.
2. **Communicate as a human**, not a bot, over Slack/Teams.

More get added as new edge cases come up. Open an issue to propose one.

## Deploying

This is a single static HTML file. To publish via GitHub Pages: merge this
branch, then enable Pages in repo settings pointed at the branch root — no
build step required.
